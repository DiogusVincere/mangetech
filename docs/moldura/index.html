MangeTech app

App Flutter de chamados de manutenção e gestão de ativos

Abre e acompanha chamados do chão de fábrica, cadastra equipamentos com QR code e mostra o dashboard da gestão, usando a API Django do projeto. Esta é a versão web do app, rodando dentro de uma moldura de celular. Use o mouse como se fosse o dedo.
